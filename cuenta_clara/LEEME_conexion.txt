Conexión a la base de datos de cuenta_clara
==========================================

cuenta_clara ya NO necesita conexion.php. Se conecta sola (config.php, función conectar())
con los mismos datos que usan las demás páginas del proyecto:

  host    gustavorm-gustavorm.i.aivencloud.com   (variable opcional DB_HOST)
  usuario avnadmin                               (variable opcional DB_USER)
  base    defaultdb                              (variable opcional DB_NAME)
  puerto  25926                                  (variable opcional DB_PORT)
  clave   variable de entorno DB_PASSWORD        (obligatoria)

Si no hay clave o no conecta, la página sigue funcionando solo con las cuentas de prueba, y el
motivo exacto queda en el log del servidor (error_log).

Base de datos: ejecuta base_de_datos.sql bloque por bloque en defaultdb. Requiere PHP 8.1 o superior.

Cuentas de prueba (sin base de datos), todas con contraseña 1234:
demo (Camila Torres) y demo2 (Mateo Gómez).
En las cuentas de prueba también se puede agregar dinero, pero esos abonos solo duran mientras la sesión esté abierta.

Agregar dinero (cuentas registradas): cuenta.php llama a sp_cuenta_agregar_abono. Ejecuta de nuevo ese bloque de
base_de_datos.sql para tener la versión actualizada del procedimiento.

AHORROS (pantalla ahorros.php, se abre desde "Ir a Ahorros" en la cuenta)
Usa otra base de datos, banco_ahorros, con una sola tabla: ahorros (id, saldo, ahorro). Se crea con ahorros.sql.
El procedimiento sp_ahorrar resta el valor del saldo y lo suma al ahorro. Avisa si el cliente no existe,
no tiene saldo (cero) o el valor es mayor al saldo. Opcional: la variable AHORROS_DB_NAME cambia el nombre de la base.
